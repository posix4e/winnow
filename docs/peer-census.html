How to read it

Usable means the handshake completed and the node advertises NODE_COMPACT_FILTERS; Winnow refuses anything else at the door. At the tip means within a hundred blocks of the median reported height, the same tolerance the wallet's pool applies before unseating a peer. Stuck at the split means reporting a height within twenty blocks of 961,632, where the BIP-110 minority chain left the main chain on 2026-08-08 and stopped. Claiming a taller chain means reporting a height more than ten blocks above the tip: a node on some other chain, or lying.

Endpoints, not nodes. One node can listen on clearnet, Tor and I2P at once, and Bitcoin Core deliberately makes linking a node's addresses across networks hard, so the census cannot tell how many endpoints are doors into the same node. Distinct usable nodes lie somewhere between the clearnet count and the total.

The census judges what a node reports, never which software it runs. The family column is there because the answer turned out to depend on it. Tor and I2P nodes are dialled through a local SOCKS5 proxy when the run has one; a day without a network row did not dial that network. Per-node detail is kept as a two-week workflow artifact; this page carries aggregates only, read from the repository's census-data branch so the wallet's own history never carries a daily commit.
