Winnow 0.8.3: the peer list ships with the app

Winnow no longer downloads its peer list. Each release carries the census of the day it was built, and the wallet starts from it. Nothing reaches census.winnowwallet.com or its I2P mirror any more, so Tor-only and I2P-only wallets need no web request to find peers.

Peer list

In Advanced → Settings → Mainnet peer list, the list's date and peer counts should show, and Refresh peer list is gone. A fresh mainnet install should find peers and sync, including with only Tor or only I2P allowed.

Upgrading from an older version

Check that your accounts, transaction history, backups, routing and saved settings remain available after the update.

Report bugs publicly at https://github.com/winnowwallet/winnow/issues. Include the app version, device, network, routing mode and steps to reproduce. Never include recovery words, private keys, or wallet backup files.
