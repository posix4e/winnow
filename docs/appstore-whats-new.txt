• Silent payment codes. Send accepts a BIP352 code (sp1…) and pays it to an address made for that transaction alone. The receipt shows the code beside the address it paid. A person can be saved from a code and paid again and again, with a fresh address each time.
• Multisig accounts in Advanced mode. Build a k-of-n Taproot account from this phone's key and other signers' keys, or join one by pasting its descriptor. Any k signers spend it by passing a PSBT between them. An optional recovery path lets fewer signers, or a separate key, spend a coin that has not moved for a set number of blocks.
• Shared savings, cosigner cards and payment approvals are retired, and MuSig2 accounts along with them. Simple mode is the everyday wallet: balance, receive, send, activity and backup. A backup that carries a MuSig2 account is refused rather than restored without it.
